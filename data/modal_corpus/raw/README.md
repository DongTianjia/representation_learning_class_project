## Description
Corpus de dialogues italiens, anglais et français, annotés pour la modalité épistémique. 

Environs 20.000 mots par langue, 2842 constructions épistémiques annotées (833 pour le corpus anglais, 1271 pour le corpus français, 720 pour le corpus Italien)  .
